# SKILLS.md - Roles del Escuadrón (48h)

Para ejecutar este MVP bajo extrema presión, el equipo debe dividirse estrictamente por roles sin solaparse:

### 1. Data Scientist / ML Engineer
*   **Habilidades:** Python, Kaggle, manejo de APIs de la NASA, procesamiento de tensores/arrays.
*   **Misión:** Consumir MODIS y Sentinel-1/NISAR, limpiar los datos y escupir un archivo GeoJSON cruzado con los polígonos de riesgo.

### 2. Frontend / UI Developer
*   **Habilidades:** JavaScript, React, Mapbox GL JS, CSS.
*   **Misión:** Construir el mapa interactivo en Dark Mode. Debe clavar la estética fintech/alto-contraste con acentos púrpuras.

### 3. Geotechnical / Civil Lead (Domain Expert)
*   **Habilidades:** Ciencias de la Tierra, Ingeniería Estructural, software Autodesk, QGIS.
*   **Misión:** Guiar la lógica del modelo. Asegurar que las variables que se están cruzando tengan sentido físico real para calcular el riesgo de colapso de infraestructuras.

### 4. Pitch / Video Editor
*   **Habilidades:** Edición de video rápido, motion graphics, storytelling.
*   **Misión:** Empezar a guionar y maquetar el video de presentación vertical el mismo sábado.
